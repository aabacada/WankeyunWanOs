WanOS 应用市场（镜像）

目录克隆：官方应用目录 API + 2026-11-06 设备导出合并而成，共 81 个应用。 安装包、安装脚本仍指向官方 CDN（wanos.xyz / wxqun988.vxjuejin.com），本仓库不重传二进制文件。 仅供自己设备安装使用，与 WanOS 官方无关。

安装方式：在 WanOS 设备上以 root 执行安装脚本，例如 curl -fsSL https://wanos.xyz/downloads/apps/openlist/install.sh | sh， 或点卡片里的“安装脚本”查看。不要在非 WanOS / 非 ARMv7 设备上直接跑这些脚本。

数据来源：app-store-api-20260721.json（官方 API，更新于 2026-07-21）+ 设备导出 upload.md（2026-11-06）。 更新方法：跑 update.sh 重新拉取官方 API 再生成 apps.json。

本站点为 WanOS 官网资源离线镜像：安装包走 GitHub Releases，安装 / 更新 / 卸载脚本与图标走 GitHub raw，官网下线后仍可安装。原始官方目录见 apps.json，缺口见 github-mirror/README.md。
