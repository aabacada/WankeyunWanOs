## 快速开始

**第 1 步：连接设备**
把玩客云接入路由器，等待系统启动后，在同一局域网浏览器访问设备 IP。首次进入按页面提示设置管理员密码。

**第 2 步：插入硬盘**
插入 USB 硬盘后系统会自动检测并挂载。桌面右下角会显示硬盘通知，文件管理器和媒体库会读取已挂载目录。

**第 3 步：上传和管理文件**
打开文件管理器，可上传、下载、新建、重命名、复制、剪切、删除、解压和编辑文本文件。

**第 4 步：移动端连接**
手机 APP 可自动扫描局域网 WanOS，也支持手动输入 IP、域名和端口。开启内网穿透后，APP 首页可切换为公网域名访问。

## 系统桌面

桌面是 WanOS 的主入口，常用功能以图标和窗口形式打开。窗口只允许顶部标题栏拖动，正文区域可正常选择和复制文字。

- **我的系统**：查看系统版本、内核版本、设备唯一码、硬件信息、存储、内存和运行状态。
- **应用导航**：集中打开系统内置应用和用户安装的应用，终端功能已直接开放。
- **系统通知**：右下角通知面板展示公告、系统事件、新版本提示和硬盘插入通知。
- **系统使用说明**：桌面说明入口会打开本文档 `wanos.xyz/doc.html`。

## 文件与分享

文件管理器是日常使用最频繁的模块，支持本地硬盘目录浏览和常见文件操作。手机 APP 文件页做了缓存优化，短时间返回页面会复用当前列表，下拉刷新才重新读取。

| 功能 | 说明 |
| --- | --- |
| 上传 / 下载 | 电脑端支持拖拽上传，APP 端支持照片、视频和文件上传。下载由 WanOS 设备本地完成。 |
| 目录操作 | 新建文件夹、新建文件、重命名、删除、复制、剪切、移动和解压压缩包。 |
| 文本编辑 | 常见文本文件可直接打开和保存，适合修改配置和记录内容。 |
| 文件分享 | 可创建分享链接和提取码，分享管理里可查看、复制和取消分享。 |

## 媒体播放与相册

系统复用固件内置媒体服务能力，前端改成适合家庭使用的视频墙和相册瀑布流。媒体封面优先读取设备端生成的缩略图。

- **视频墙**：自动收集硬盘里的视频，按封面墙展示，点击后弹出播放器播放。
- **相册**：图片以纵向瀑布流显示，支持懒加载，点击图片可放大预览。
- **目录设置**：视频墙和相册都可以设置指定目录；未选择目录时默认全盘扫描。
- **电视端**：TV 版支持局域网扫描、手动连接、视频、音乐、图片分类和遥控器焦点操作。

## 下载中心

下载中心对接设备端下载服务，面向 HTTP、磁力、BT 种子和 Transmission 常用操作。

- **添加任务**：支持链接、磁力链接和 BT 文件上传解析。
- **任务管理**：支持开始、暂停、删除、查看详情、选择保存目录和查看速度状态。
- **Transmission 能力**：保留基础任务列表、文件详情、tracker、校验和重新汇报等常用功能。
- **系统更新等待**：安装应用和在线更新都有等待动画，避免误以为页面卡住。

## 网络访问与共享

WanOS 同时提供局域网访问和远程访问方案，适合家庭电脑、手机、电视和外出时临时访问。

| 模块 | 用途 |
| --- | --- |
| 内网穿透 | 开通后会分配远程访问地址。APP 首页只有检测到穿透已开启时才显示“内网穿透”切换按钮。 |
| Samba 网络共享 | 面向 Windows、macOS 和局域网文件访问，可设置共享目录、共享名、读写权限和 SMB1 兼容。 |
| WebDAV | 固件内置 WebDAV 服务，适合 Windows 网络位置、手机文件管理器和第三方同步工具。 |
| 网站发布 | 可指定目录发布个人页面或临时文件展示页，方便在局域网或远程访问。 |

> ⚠️ **注意**：公网访问涉及账号密码和设备安全，建议只给可信用户使用，并定期检查共享目录权限。

## 系统维护

- **磁盘管理**：查看磁盘和分区，支持挂载、格式化 ext4，并保护系统盘避免误操作。
- **硬盘健康**：读取硬盘健康和容量状态，帮助判断硬盘是否异常。
- **计划任务**：桌面和 APP 都可以创建、编辑、启停和删除计划任务。
- **在线更新**：设备读取官网更新服务，下载更新包并自动等待服务恢复。
- **后端服务**：可配置自定义后端程序的启动命令、工作目录、监听地址，并进行启动、停止和重启。
- **备份迁移**：导出和导入桌面配置、应用入口等必要配置。

## 手机 APP 和电视版 APP

手机 APP 使用 uni-app 传统项目开发，功能对齐电脑端；电视版 APP 使用 TV 焦点组件，适合遥控器操作。

| 客户端 | 能力 |
| --- | --- |
| 手机 APP | 自动扫描局域网设备、手动连接、文件管理、图库、视频墙、设备管理、下载中心、计划任务、共享和系统更新。 |
| 电视版 APP | 扫描 WanOS、输入密码连接、视频/音乐/图片分类、搜索、播放、图片预览和遥控器返回。 |
| 连接模式 | 局域网默认使用设备 IP；开启内网穿透后可切换到分配的公网域名。 |

## 应用中心

应用中心用于安装和管理扩展应用，安装后可在桌面生成入口，方便打开应用界面。

- **安装应用**：支持安装脚本 URL、启动服务、打开 Web 管理界面。
- **桌面入口**：安装成功后显示图标；卸载后会同步移除入口。
- **运行控制**：支持启动、停止、卸载和重新打开应用。
- **统一入口**：常用应用会出现在桌面和应用导航里，使用时不用记地址。
